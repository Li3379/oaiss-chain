### 1.2 活文档治理原则
1. **单一真相源 (Single Source of Truth, SSOT)**：所有架构设计、数据库实体、REST 端点以代码与自动化断言为唯一基线，拒绝文档与代码漂移。
2. **代码零漂移断言保障**：通过 `node scripts/gates/doc-verify.mjs` 对文档声明事实进行实时断言。
3. **CI 交付闭环门禁阻断**：所有发布流水线通过 `node scripts/gates/closure-audit.mjs` 强制核验成果交付物物理完整性与证据闭环。

| 术语 / 缩略语 | 英文全称 | 中文含义与系统业务定位 |
| :--- | :--- | :--- |
| **OAISS** | Online Autonomous Intelligent Settlement System | 链上自律智能核算结算系统（系统代号） |
| **CEA** | China Emission Allowance | 全国碳排放配额 |
| **CCER** | China Certified Emission Reduction | 国家核证自愿减排量 |
| **Fabric** | Hyperledger Fabric | Linux 基金会开源企业级联盟链底层框架 |
| **Chaincode** | Smart Contract on Fabric | 运行于安全容器内的联盟链智能合约 |
| **XAI** | Explainable Artificial Intelligence | 可解释性人工智能技术（用于碳价敏感度归因） |
| **ELI5** | Explain Like I'm 5 | 极简友好的用户交互设计范式，降低工业与双碳专业门槛 |
