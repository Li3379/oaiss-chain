## 第一部分 · 我理解到的系统是什么

### 1.1 业务主干（一条链）

```
企业填报原始数据(25参发电/9参电网)
  → 国标模型核算(GB/T 32150)
  → 企业确认(私钥 RSA 签名, SHA256withRSA)
  → 审核员端 RSA 验签 + 人工核材料
  → 通过 → 报告自动上链(Fabric/Mock)   [方案 A：REVIEWER 触发]
  → 碳配额可用 → 交易(P2P / 双向拍卖集合竞价 30s)
  → 碳币结算 → 信誉分/等级 → 碳中和项目 → AI 预测
  → 第三方监管只读穿透 + 定期核查
  → 管理员：准入证书 / 资格证 / 系统配置 / 撮合控制台
```

### 1.2 四角色职责边界（方案 A 定稿，已由门禁断言）

| 角色 | 做 | 明确不做 |
|---|---|---|
| ENTERPRISE | 填报、RSA 签名、挂单/发起交易、碳中和项目、AI 预测 | 审核、上链、发证 |
| REVIEWER | 审核碳报告/项目；**审核通过即自动上链**；核证；可扣分 | 用户管理、签发证书 |
| THIRD_PARTY | 监管大屏、只读穿透、定期核查 | **任何业务写操作**、上链审批 |
| ADMIN | 用户管理、准入/资格证签发、系统配置、撮合控制台、兜底上链 | 代行常规上链 |
