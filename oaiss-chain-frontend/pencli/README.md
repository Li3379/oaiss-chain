# 双碳链动系统 · 全站高保真原型

本目录是用 Pen（原 Pencil）MCP 直接在 `.pen` 画布上生成的全站原型，覆盖 `oaiss-chain-frontend` 路由表中的全部 28 个页面。

## 怎么打开

- **浏览器浏览全部页面**：[index.html](./index.html)（推荐，可直接看缩略图并点开大图）
- **编辑源文件**：用 Pen / Pencil 打开 [UI_Desgin.pen](./UI_Desgin.pen)
- **单页大图**：`png/` 目录，文件名即页面中文名，1440×900 像素

## 视觉方向：石墨台账（浅色·极克制）

废物不沿用原前端青绿渐变，采用基于 247 个获奖网站研究（design-taste-frontend）与 ui-ux-pro-max 配色库筛选出的浅色克制风格：铬件零彩色、墨色主操作、一个蓝色只用于主数据。

| 令牌 | 值 | 用途 |
|---|---|---|
| 底色 ground | `#F8F8F8` | 页面底 |
| 卡面 surface | `#FFFFFF` | 卡片、面板 |
| 抬升面 raised | `#EEEEEE` | 次级按钮、表头 |
| 发丝线 border | `#E6E6E6` | 1px 边框与分隔 |
| 主文字 | `#0A0A0A` | 标题、数值 |
| 次文字 | `#5F5F5F` | 正文 |
| 弱文字 | `#6B6B6B` | 标签、时间戳（AA 5.0+） |
| 强调 墨色 | `#141414` | 主操作按钮（白字） |
| 图表蓝 | `#1D5FBF` | 唯一主数据色 |
| 成功 | `#2E7D32` | 正向数值 |
| 危险 | `#C4242A` | 驳回、失败 |

- **字体**：中文 Noto Sans SC；数字、哈希、编号统一 JetBrains Mono，靠等宽对齐强化「台账读数」感。
- **形状**：圆角统一 8px（卡片）/ 6px（控件），无阴影、无渐变、无圆环饼图。
- **图标**：全部 Lucide 线性图标，无 emoji。
- **克制度**：铬件（外壳）不含任何品牌色；主操作是近黑墨色徽章，唯一蓝色用在主图表数据上，其余全部墨字+灰字。

- **图标体系**：统一 Lucide 线性图标，尺寸收敛到三档 —— 导航/数据卡 18px、工具栏/输入框 16px、按钮内 14px；状态用 5px 圆点+浅底标签，无 emoji、无混用粗细。

## 页面配图（一页一处）

配图标准引用 design-taste-frontend 的 `references/imagery.md`：**真实世界照片胜过插画**（§3），**已展示数据/界面的页面不再放同义插画**（§7）。因此只保留语义成立的实拍图：

| 页面 | 配图 | 位置 | 成立理由 |
|---|---|---|---|
| 03 登录 | 晨雾森林航拍 | 左栏叙事区下方 | 碳汇意象，真实自然场景 |
| 05 碳中和项目 | 光伏电站航拍 | 表格下方通栏 | 项目列表里第一个就是「分布式光伏一期」，图与数据直接对应 |
| 14 区块链浏览器 | 数据中心机房照片 | 表格下方通栏 | 联盟链的物理载体，真实设备而非发光特效 |

**明确不加图的页面**：

- **02 官网首页**：信息密度已满，加图会压暗链上事件流。
- **08 数据可视化**：本身已是图表界面，再放图表插画是同义反复的装饰（`imagery.md` §7）。该页的加强改为图表系列色（蓝色阶梯）。
- 其余数据表/表单页：同理保持纯信息呈现。

图片统一处理：圆角 8px、四周留白不贴边、cover 填充、色调贴合页面灰白底。

## 壳层结构

顶栏主导 + 左侧细导航（72px 图标栏）：

- **顶栏**：品牌标识 → 一级页签（碳核算 / 交易市场 / 企业资产 / 数据智能）→ 链上状态指示灯 → 搜索、通知、用户区。
- **左侧细栏**：11 个图标入口，当前页有柠黄绿竖条标记。
- **页头**：面包屑 + 标题 + 一句话职责 + 右侧主次操作。
- **内容区**：统计条 → 筛选器 → 面板（表头 44px，内含表格 / 图表 / 表单）。

## 数据来源

原型中的企业名、报告编号、状态枚举、链上哈希、信用分、配额数值全部来自：

- `oaiss-chain-frontend/src/views/**/*.vue` 的真实字段与按钮文案
- `oaiss-chain-frontend/src/utils/status-meta.ts` 的状态枚举（0 草稿 / 1 已提交 / 2 审核中 / 3 审核通过 / 4 审核拒绝 / 5 已上链）
- `oaiss-chain-backend/src/main/resources/db/migration/V2__seed_data.sql` 的种子数据

因此原型中的业务语义与实现一致，可直接作为验收与二次开发的参照。

## 规范约束

- 每页固定 1440 × 900，相当于 1440 桌面视口首屏。
- 表格列宽、状态标签配色、按钮主次层级在所有页面统一。
- 空态、错误态、权限受限态在设计稿中以独立提示条形式给出（如「上链补救」的存证目标说明、「AI 企业推理」的离群扰动告警）。
- 危险操作（吊销证书、确认扣分、终止项目）均为次级描边按钮，不用主色，避免误触。
